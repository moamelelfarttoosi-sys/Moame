# Ready-to-Fill Skeletons

Placeholders are in `[square brackets]`. Never silently replace a placeholder with an invented value —
hand the list of unfilled placeholders back to the user.

---

## 1. Outgoing letter (English)

```
[LETTERHEAD — colour logo, entity name, branch line]

Ref. No.: [____/____]                                       Date: [DD.MM.YYYY]
In reply to: [Ref. No. ____ dated DD.MM.YYYY]        ← only if this is a response

Attn.: [Mr./Mrs./Dr./H.E. Full Name]
[Position]
[Organisation]
[Mailing address, if applicable]

Subject: [Single, specific subject — one issue only]

Dear [Sir / Madam / Sirs],

[Part 1 — Grounds. State the facts, events, or reference the prior documents that give rise to
this letter. "We refer to …", "Further to …", "In accordance with Clause X of …".]

[Part 2 — The ask. State the conclusion, proposal, request or resolution. If there are several,
break them into numbered paragraphs.]

Attachments:  1. [Title] … on [N] pages
              2. [Title] … on [N] pages

Yours faithfully,

[Position]                          [Signature]                    [Full Name]
[(by Power of Attorney No. ____ dated DD.MM.YYYY) — if applicable]

[Executor Full Name]
[(+964) ___-__-__]                  ← omit entirely for NOC and state authority letters
```

## 2. Bilingual letter (English–Arabic), two-column layout

```
| ENGLISH                                  | العربية                                   |
|------------------------------------------|-------------------------------------------|
| Ref. No.: [____]  Date: [DD.MM.YYYY]     | [الرقم / التاريخ]                          |
| Attn.: [Name, Position, Organisation]    | [الاسم، المنصب، الجهة]                     |
| Subject: [Subject]                        | الموضوع: [الموضوع]                         |
| [Part 1 — grounds]                        | [الفقرة الأولى — الأسانيد]                 |
| [Part 2 — request]                        | [الفقرة الثانية — الطلب]                   |

This document is provided in Arabic for informational purposes only; the English text
shall prevail in case of any discrepancies.
```

Keep paragraph numbering identical in both columns. Translator confirmation must accompany the
registration request.

## 3. Office Memorandum

```
[LETTERHEAD]

                              OFFICE MEMO

Ref. No.: [____]                                            Date: [DD.MM.YYYY]

To:       [Full Name, Position]              ← one addressee only
Copy to:  [Full Name, Position]              ← optional readers

Subject: [Heading]

[Body — grounds, then the request or the decision sought. Keep to matters that genuinely
require formal documentation; routine operational matters do not belong here.]

Attachments: 1. [Title] … on [N] pages

[Position]                          [Signature]                    [Full Name]
```

Director's resolution block, top right of the title page once returned:
```
APPROVED / REJECTED
By e-mail [DD.MM.YYYY]
[Full Name]
Director
[Signature]
```

## 4. Order on principal activity

```

                                 ORDER

No. [__/ENTITY]
Date: [DD.MM.YYYY]

Re: On [concise statement of subject]

[Recital — the reason and purpose of issuance. Where the basis is another enactment, give
its type, number, date, title and relevant provisions.]

I HEREBY ORDER

1. [Position, Full Name] by [DD.MM.YYYY]:
   1.1. To [infinitive verb + specific task].
   1.2. To [infinitive verb + specific task].
2. To approve [title of the attached regulation] in accordance with the Attachment to this Order.
3. To consider Order No. [__/ENTITY] dated [DD.MM.YYYY] null and void.
4. [Position, Full Name] shall assume responsibility for monitoring execution of this Order.

This Order constitutes an entire and integral document with effect immediately upon signing hereof.

[Position]                                                        [Full Name]
                                    [Signature]

Drafted by: [Name]
Ext.: [____]
```

Attachment header, top right of every attachment:
```
                                                              Attachment
                                  to Order No.___/ENTITY dated_______.20__
                                            of [Full legal entity name]
```

## 7. Risk and Controls Matrix

| 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
|---|---|---|---|---|---|---|---|---|
| No. | Objective code | Objective | Process code | Process (operation/transaction) | Risk code | Controlled risk description | Control code | Control procedure |
| 1 | O-01 | [Objective, linked to clause X.X] | P-01 | [Process] | R-01 | [Adverse event affecting the objective] | C-01 | [Control, cross-referenced to clause X.X] |
| 2 | O-01 | [same objective → same code] | P-02 | [Process] | R-02 | [Risk] | C-02 | [Control] |

Optional additional columns: likelihood of occurrence; impact magnitude; risk mitigation measures;
person responsible for control and management.

Rule of thumb: if a risk row cannot cite a clause number, either the clause is missing from the
regulation or the risk does not belong in the matrix.

```
Best regards,
[Full Name]
[Position]
[Company name, Asset/Block]
Mobile: [+964 ___ ___ __ __]
Extension: [____]                    ← optional
[Office address]                     ← optional
E-mail: [name@domain]
```

Calibri or Times New Roman 11–12 pt, black or dark blue, left-aligned, single spacing.
No logos, photos, hyperlinks, slogans or decorative symbols.
