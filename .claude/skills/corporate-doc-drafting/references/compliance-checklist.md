# Pre-Delivery Compliance Gate

Run this before handing over any document produced under this skill. Report the outcome explicitly:
either "all items clear" or a list of what fails and what the user still has to supply. Never pass
silently over a missing item by inventing a value.

## A. Universal — every document

- [ ] Correct entity label used for the audience — **Operator** / **Company** / **Asset**
- [ ] Official letterhead (or blank sheet if jointly prepared by two or more organisations)
- [ ] Document type name in CAPITALS, centred — omitted only for outgoing letters
- [ ] Date present and correct per the date rule (registration date, or the type-specific exception)
- [ ] Placeholder for the registration number, clearly marked as to be filled
- [ ] Heading present and specific
- [ ] Attachments record with page counts; every attachment referenced in the body
- [ ] Executor record where the type requires it — omitted for NOC and state authority letters
- [ ] Signature block complete: position, signature line, full name; POA number and date if signing under POA
- [ ] Times New Roman 12 (14 for Russian to the parent company); justified; 1.15 line spacing
- [ ] Margins L 20–25 / R 15 / T 20 / B 20 mm; A4
- [ ] No italics, no underlining, no colour, no hyphenation
- [ ] Confidentiality mark applied where content warrants it

## B. Outgoing letters

- [ ] One issue only
- [ ] Two-part structure: grounds → request/conclusion
- [ ] Addressee block upper left, lowercase except initials, nominative case, no quotation marks
      around company names in English
- [ ] Four addressees maximum, no "CC" before the 2nd–4th; distribution list prepared if more
- [ ] No regulatory content — clarification only
- [ ] Supporting materials assembled if submitting for the Director's signature
- [ ] To the parent company: only the Director signs; file naming convention applied
- [ ] To the NOC / state authorities: two pages maximum recommended; "Drafted by" omitted; legal
      review path or the direct-Director-approval exception confirmed; translator confirmation
      attached if Arabic

## C. Bilingual documents

- [ ] Prevalence clause included verbatim
- [ ] Paragraph numbering identical across both language columns
- [ ] Arabic text proofread by the translator, confirmation attached to the registration request

## D. Orders and Directives

- [ ] First-person singular; heading opens with "On"
- [ ] Recital states reasons and legal/regulatory basis with type, number, date, title
- [ ] Opens with "I HEREBY ORDER" (order) or "I HEREBY OBLIGE" (directive)
- [ ] Every instruction has task + numeric deadline + named Executor
- [ ] Intermediate milestones set where the timeframe exceeds three months
- [ ] Infinitive verbs; no vague wording
- [ ] No duplication of, or contradiction with, an existing order; amendments/cancellations stated explicitly
- [ ] No "shall be communicated to…" phrase; distribution list used instead
- [ ] Final paragraph assigns responsibility for monitoring execution
- [ ] Two pages maximum, excluding attachments
- [ ] Attachment notation block in the top right corner of each attachment
- [ ] Issuer's job title left-aligned, surname and initials right-aligned
- [ ] Numbering format `Number/Entity` (personnel orders: `Number/Asset`)

## E. Minutes of Meeting

- [ ] Date = meeting date (last day if multi-day)
- [ ] First page on letterhead
- [ ] Introductory section: CHAIRPERSON / SECRETARY / ATTENDEES / AGENDA
- [ ] Main section in HEARD / SPOKE / RESOLVED form per agenda item
- [ ] Every RESOLVED item carries action, deadline, and named Executor/Co-Executor
- [ ] Circulation within three business days noted; comment window three business days
- [ ] JMC or subcommittee minutes deferred to the JMC's own Rules and Procedures

## F. Local regulations and OTD

- [ ] Correct type for the business-process level (Procedure / Guidelines / Instruction / Methodology)
- [ ] Full mandatory structure present and in order: Title Sheet → Revision history log → TOC →
      General Provisions → References → Terms → Body → Attachments
- [ ] Title's first word is the document type in CAPITALS
- [ ] TOC lists paragraphs, sections, subsections and attachments with page numbers and clickable links
- [ ] Revision history log at section granularity; Rev 00 marked "First Issue"
- [ ] General Provisions cover issue/purpose, document type and business process, basis documents,
      area of application, essential terms — plus exclusions
- [ ] **Risk and Controls Matrix attached as the final pages of the PDF** — this is a hard stop
- [ ] RCM codes present in columns 2, 4, 6, 8; every risk traced to a numbered clause; every control
      traced to a named owner
- [ ] Approving Order drafted separately, Clause 1 "To approve…", Clause 2 "To consider… null and void"
      where superseding
- [ ] Explanatory note (max 2 pages) and distribution list prepared, both for Supervisor signature
- [ ] Business Process Model prepared
- [ ] No unadapted copy-paste from external documents
- [ ] OTD: business process identified against the Register before drafting; DDM updated; one Order
      covers one document at one revision only

## G. Assignments and resolutions being drafted

- [ ] Resolution vs Assignment chosen deliberately
- [ ] First-named person is the intended Responsible Executor
- [ ] Deadline stated, or the applicable standard deadline noted
- [ ] Progress-comment expectations conveyed — no "in progress" / "completed"

## H. Final sweep

- [ ] No fabricated numbers, dates, POAs, or signatories anywhere in the document
- [ ] Every placeholder visibly marked and listed for the user
- [ ] Cross-references resolve to the correct paragraph numbers after any renumbering
- [ ] Run `zero-error-review` for substantive correctness
